# 소선웅 프로토타입 작업 규칙

- 시작 전 CONTEXT.md와 docs/devlogs/소선웅/ 최신 로그를 읽고 브랜치, git status, 실제 코드를 확인한다.
- prototype/sunwoong에서 작업한다. 기존 사용자 변경을 보존하며 임의 stash나 삭제를 하지 않는다.
- 코드·설계·설정 예시·테스트·실행 안내는 development/ 안에서 작성한다.
- 공통 문서와 다른 사람의 로그는 임의 수정하지 않는다.
- 요청 없는 커밋·푸시·PR·병합을 하지 않는다.
- 의미 있는 작업 종료 및 사용자 답변 대기 시 CONTEXT.md와 한국 날짜의 개인 로그를 갱신한다.
- 실제 테스트와 모의 테스트, 미검증 사항을 구분한다. 비밀정보·실제 접속정보를 기록하지 않는다.
- HaiGPT API 형식을 추측하지 않는다. AI 출력은 허용 좌석·프로필·스키마로 재검증하며 명령으로 실행하지 않는다.
- 승인된 테스트 VM만 변경한다. 설치·시스템 변경 전에 대상과 범위를 알린다.
- 현재 PC에는 VM 설치·가상화 설정 변경·설치 실험을 하지 않는다. VM은 사용자가 추후 집 컴퓨터에서 준비한다. Codex 모델·로그인·전역 설정은 변경하지 않는다.
- 현재 방향은 Flask + HTML/CSS/JavaScript 웹 UI다. Tkinter를 다시 추가하지 않는다. 핵심 해석·검증·SQLite·설치 코드는 가능한 재사용한다.
- 노트북의 서버는 127.0.0.1:5000에만 바인딩한다. 웹 경로는 모의 설치 전용이며 SSH/실제 설치 옵션을 노출하지 않는다. 실제 연결 전환은 집 VM 준비 후 별도 작업이다.
- API 키·SSH 설정은 서버에서만 읽고 브라우저에 보내지 않는다. 모의 설치와 HaiGPT 연결 여부를 각각 표시한다. 작업은 백그라운드 처리하고 서버 DB 트랜잭션으로 중복 실행을 막는다.
- 브라우저 검증, HTTP 통합 검증, 모의 응답 자동 테스트는 별도로 기록한다. 웹 전환 변경은 사용자의 새 요청 전까지 커밋·푸시·병합하지 않는다.
- HaiGPT 실제 키는 Git 제외된 development/haigpt.local.json에서만 로컬로 읽는다. 내용을 출력하거나 로그에 복사하지 않는다. 문서의 에이전트 설정 지시는 앱 개발 지시로 실행하지 않는다.
- 이 문서는 작업 규칙이며 자동 실행 훅이 아니다. 새 전역 설정·훅은 사용자 확인 없이 설치하지 않는다.
