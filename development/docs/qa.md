# 테스트 및 검수

## 자동 검증 결과

팀 저장소 development/로 재배치 후 Python 3.13의 비-Windows 테스트 환경에서 아래 검사를 재실행했습니다. Windows 배치 파일 및 UI 실행은 검증하지 않았습니다.

- Python 문법 검사: `python -m compileall -q src tests` 통과.
- API 회귀 테스트: `python -m tests.smoke` 통과 (테스트 전용 임시 SQLite DB, AI 응답 모의 처리, PC 에이전트 HTTP 요청 모의 처리).
- 검증 범위: 권한 검사, 파일 등록 및 해시, AI 파일 선택과 다운로드, 존재하지 않는 파일 차단, PC 등록 및 인증, 두 PC의 작업 배정 및 완료 기록.

## 현장 테스트 체크리스트 (미실행)

- [ ] Windows에서 setup.bat/start.bat 실행
- [ ] 관리자 및 사용자 웹에 접속, 접근 키 검사
- [ ] 실제 Ollama 요청 및 브라우저 파일 다운로드
- [ ] 동일 LAN의 다른 PC에서 사용자 웹 접속
- [ ] 두 대 이상의 실제 Windows PC에서 agent.ps1 실행 및 병렬 다운로드 확인
- [ ] 파일 SHA-256 및 작업 결과 확인

추가 API 테스트: 설치 작업 권한, 파일 유형 제한, 로컬 승인 해시 일치 여부, 설치 응답 기한 만료 후 재배정 금지, 결과 기록. 모의 설치이며 실제 설치 EXE를 실행하지 않았습니다.

- [ ] 실제 Windows x64 PC에서 공식 Python 서명 검사 및 현재 사용자 자동 설치
- [ ] 설치 후 정확한 버전 및 예제 출력 확인
- [ ] 두 PC에서 동일 설치 요청 수행

HaiGPT 연동 및 타 프로그램 자동 설치는 미구현입니다.

## PC별 다운로드 개정 검증

Python 문법 검사와 API 회귀 테스트 통과. 업로드 후 비공개, PC별 배포 권한, 잘못된 PC 키 및 숨겨진 파일 차단, 서명 변조/만료 차단, 파일명 검색 및 버전 불일치, Ollama 번호 선택(모의 응답), 기존 설치 작업을 검증했습니다. 실제 Streamlit 브라우저 자동 다운로드 및 Ollama 실행은 이 환경에서 검증하지 않았습니다.
