# 인수인계

Windows 다운로드·배포 프로토타입을 팀 저장소의 development/ 내부에 배치했습니다. 모든 실행 명령은 development/ 기준입니다. API 주소는 유지합니다. 사용자 웹 인증에 등록 PC 이름과 전용 키를 추가했습니다. 관리자/에이전트 인증은 유지합니다. 기존 data/ 또는 runtime/ 데이터는 필요 시 백업 후 development/runtime/으로 이동합니다. 다음 작업은 Windows 현장 검증, HaiGPT 규격 확인, Python 자동 설치 및 설치 검증의 실제 Windows 테스트, 타 프로그램 지원 검토입니다. 담당 미지정.
