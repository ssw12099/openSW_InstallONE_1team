## 오늘 변경한 내용
- 목적: FR-01(AI 개발환경 자동 설치) 개별 프로토타입의 전체 흐름 만들기
- 구조: `development/` 안을 팀 구상도 모듈 구조(src/ui·ai·installer·verification·storage·app·common)로 구성
- 요청 해석(`src/ai`): 규칙 기반 해석 + AI 해석(OpenAI 호환 방식, HaiGPT 기본 예정), AI 결과는 등록된 좌석·프로필로만 제한하고 실패 시 규칙 기반으로 대신함
- 설치(`src/installer`): Ansible 플레이북(WinRM, Chocolatey) + ansible-runner 실행기, 모의 좌석 실행기, VM용 WinRM 설정 스크립트
- 검증(`src/verification`): 좌석 검증 스크립트(Python 버전·예제 실행), 실패 단계 구분(연결·설치·검증), 이미 설치됨 표시
- 관리 웹(`src/ui`)·서버(`src/app`): 요청 → 해석 결과 확인 → 실행 → 좌석 배치도·결과 표·실행 기록·이력
- 저장(`src/storage`, `db/schema.sql`): requests, jobs, seat_results, job_events
- 도움받은 도구: Claude (코드 초안과 테스트 작성)
