# 개인 개발 로그

작업한 날 종료 시 TEMPLATE.md를 복사해 본인 폴더에 YYYY-MM-DD.md로 작성합니다.
자기 프로토타입 브랜치에 코드와 함께 커밋하고 Draft PR에 로그 링크를 공유합니다.
로그를 main에서 읽을 수 있게 옮기는 방법은 CONTRIBUTING.md의 문서 공유 규칙을 따릅니다.

오류를 해결한 과정, 실행 근거, 다른 팀원에게 필요한 요청을 중심으로 짧게 작성합니다.
통합 담당도 문서 정리·리뷰·비교·병합·통합 검증 내용을 자기 로그에 남깁니다.
키·비밀번호·민감한 원본 로그는 넣지 않습니다.
